# 历史脱敏规则模板 —— 复制成 rules.local.txt 后按需补充。
#
# 格式（与 git filter-repo --replace-text 一致）：
#     字面量==>替换文本
#     regex:正则==>替换文本
#
# ⚠️ 两条硬约束（都实测踩过，见 README「两个坑」）：
#   1. ==> 两侧不做 strip —— 必须紧贴写「旧值==>新值」，
#      写成「旧值 ==> 新值」会让匹配串带上尾随空格 → 命中 0 条且不报错。
#   2. 规则按文件顺序执行，不做长度排序 —— 长规则必须排在前面，
#      否则短前缀会先把长路径截断。下面的顺序已按此排好，别打乱。
#
# ⚠️ 本文件会被提交入库，因此**只放正则、不放任何真实值**。
#    真实值一律写进 rules.local.txt（已被 .gitignore 忽略）。

# ─────────────────────────────────────────────────────────────
# 1. 本机绝对路径
# ─────────────────────────────────────────────────────────────
# 先长后短。用户名用 [A-Za-z0-9._-]+ 泛化，不写死具体用户名。
#
# 安全前提（已实测）：本仓 upstream 全历史不含 /Users/，因此这些规则
# 不会改动上游内容、不会造成分叉。换仓库复用时请重新验证这一点：
#     git grep -nE '/Users/' upstream/main -- . | head
regex:/Users/[A-Za-z0-9._-]+/Library/pnpm/store/v[0-9]+==><pnpm 全局 store>
regex:/Users/[A-Za-z0-9._-]+/Work/dsh-pet/dsh-pet==><仓库根>/dsh-pet
regex:/Users/[A-Za-z0-9._-]+/Work/dsh-pet==><仓库根>
regex:/Users/[A-Za-z0-9._-]+==><home>

# Apple Silicon 上的 Homebrew 前缀（机器特定）。
# 注意：/usr/local/bin/electron 之类**不要**加进来 —— 那是 Electron 的
# 标准系统安装位置回落，属跨平台源码，清洗会破坏代码。
# 用 [/] 拆写 /opt/homebrew 与 node_modules：避免本文件里的规则字面量
# 被 rewrite 自身命中（已踩过：工具文件被自己的规则替换）。
regex:/opt[/]homebrew/lib[/]node_modules==><全局 node_modules>

# ─────────────────────────────────────────────────────────────
# 2. 凭据文件位置
# ─────────────────────────────────────────────────────────────
# 只匹配带 ~/.dsh/ 前缀的形态。源码注释里的裸 `.credentials.yaml`
# 是上游 balance.ts 既有内容，故意不匹配（改了会与上游分叉）。
regex:~?/?\.dsh/\.credentials\.yaml==>$DSH_HOME 下的 credentials 文件

# ─────────────────────────────────────────────────────────────
# 3. 个人账户数字 —— 默认留空，按扫描结果手工补
# ─────────────────────────────────────────────────────────────
# 不要写「所有 ¥金额」的正则。同一个字面量在本仓有三种含义：
#   · ¥8.79 / ¥20   → 上游 README 示例值，改了会与 upstream 分叉
#   · ¥0.00         → 「假 0 防线」的正当代码字面量，改了破坏语义
#   · ¥1xxx.xx 等   → 真实账户余额，必须清掉
# 正则区分不了这三者，所以由 scan-secrets.sh 报出来、人工补字面量。
#
# 补的时候：长值排前面（如 ¥1xxx.xx 要在 ¥1xxx 之前），且紧贴 ==>。
# 示例（把 <...> 换成扫描器报出的真实值；下面的值只是格式示范）：
#
# ¥<真实余额1>==>¥<金额>
# ¥<真实余额2>==>¥<金额>
# <真实token数>==><tokens>
# <真实调用次数> 次调用==><N> 次调用
# <真实时间戳>==><timestamp>
